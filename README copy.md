# Traffic-ui-kit
Набор компонентов, разрабатываемых со спецификой проектов админ-панелей 
и пользовательских кабинетов команды [Traffic](https://gitlab.task4work.info/traffic-services).

## Установка
Требуется версия **node:20**
```bash
yarn install
```
## Режим разработки

- Создать базу для разработки:
  ```bash
  yarn generate-db
  ```
- Запустить json-server:
  ```bash
  yarn start:json-server:
  ```
- Запустить dev-сервер    
  ```bash
  yarn dev
  ```
По  http://localhost:5173/ откроется директория `demo`

Вновь создаваемый компонент добавляется в `src/components`, инициализируется в `src/index`.
В папке `demo` импортируется напрямую на страницу (например `App.vue`) либо регистрируется
в `main.ts`. В дальнейшем планируется директорию `demo` использовать как витрину компонентов

## Тесты 
```bash
yarn test:unit
```
Тесты находятся в `components/__tests__`

## Публикация

Для мелких правок и проверок на проектах публикация запускается вручную в пайплайне с инкрементом 
`path`. При публикации `master` увеличивается `minor`

После публикации для дальнейшей разработки в ветке следует **обновить** ветку

Minor и Major изменения следует указывать в `CHANGELOG.md`
